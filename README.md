# Desktop Control releases

Windows installers and update downloads for Desktop Control.

[Download the latest release](https://github.com/drhomet/desktop-control-releases/releases/latest)

Choose the Windows x64 **Setup.exe** installer from the release assets. After installation, open **Settings → Check for updates** to get future versions. Updates do not require a GitHub account or token. Downloads are verified before installation.

This repository contains installers, checksums, and release notes. Application source is maintained in a separate private repository.
